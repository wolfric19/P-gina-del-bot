WOLFRIC — PRIMERA VEZ EN TERMUX
================================

1) Termux desde F-Droid (no Play Store).
2) pkg update -y && pkg upgrade -y
3) termux-setup-storage
4) pkg install -y git nodejs-lts python ffmpeg
   pip install -U yt-dlp
5) cd ~
   git clone https://github.com/wolfric19/Wolfric.bot-Whatsapp.git
   cd Wolfric.bot-Whatsapp
   npm install
6) node index.js
   Vincular WhatsApp con código de 8 dígitos.
7) En el chat: .whoami
   Copiá el LID a OWNERS en index.js (nano index.js).
8) Opcional:
   export GEMINI_API_KEY=...
   export GIPHY_API_KEY=...
9) Primeros comandos: .menu  .register  .daily  .balance

No borres la carpeta sesion/
Guía larga: README.md sección "PRIMERA VEZ".
